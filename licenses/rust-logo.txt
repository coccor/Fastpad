The Rust logo

FastPad's Minimal and Solid icon sets draw Rust files with the official Rust logo, from
logo/rust-logo-single-path.svg in https://github.com/rust-lang/rust-artwork.

Changes made: the path data is unchanged; FastPad scales it into a 24x24 canvas and fills it
black, so the icon set can tint it with the theme's colour
(assets/icons/minimal/svg/rust.svg and assets/icons/solid/svg/rust.svg).
